# Política de revisión humana

Una solicitud de matrícula debe pasar a revisión humana cuando el sistema detecta:

1. Información ilegible.
2. Información ambigua.
3. Campos obligatorios ausentes.
4. Contradicciones entre diferentes partes del documento.

La revisión humana valida la información administrativa necesaria para continuar
el proceso. El sistema no debe reemplazar la decisión final institucional.
