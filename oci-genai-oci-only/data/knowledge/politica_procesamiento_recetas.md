# Reglas para reserva de matrícula

Aprueba la reserva cuando estén presentes y legibles los tres documentos
obligatorios y no exista una contradicción relevante entre ellos.

Rechaza la reserva cuando falte un documento obligatorio. Solicita revisión
humana cuando un documento sea ilegible, ambiguo o presente inconsistencias que
el modelo no pueda resolver con evidencia explícita.

La validación externa del país emisor es complementaria: confirma la existencia
del país, pero no autentica la identidad, el pago ni las notas del estudiante.
